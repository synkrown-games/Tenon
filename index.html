Paste a GitHub personal access token. A fine-grained token with Contents: read & write on just the repos you need is safest. To create repositories from Tenon, the token also needs Administration: read & write on all repositories (fine-grained) or the repo scope (classic).

Everything here is local. Your token is kept in this app's own IndexedDB on this device, and it is only ever sent to api.github.com when you pull or push. There is no Tenon server and nothing is tracked. Your projects stay in your browser too. Note that a preview run with Full access shares this editor's storage and could read the token. Disconnect removes it.
